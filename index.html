COMMON QUESTIONS

A few things worth knowing.

Lost your gear in a crash or transfer?

Send a recovery request. Staff will check what happened and review any replacement before items are sent.

Which cluster should I choose?

Legacy emphasizes convenience and quality-of-life tools. Limited emphasizes exploration and slower progression. Your choice depends on how you want to play.

Are there server wipes?

Adult ASA advertises no scheduled full wipes. The community has an inactivity policy, so old or inactive bases may still be removed. See Discord for current rules.

What mods are on the servers?

Start with our mod guide. For the current installed list, ask staff in Discord.

Are the server counts live?

We pull updates from the servers and show when they were last checked. If a server isn't reporting, we'll say so.
